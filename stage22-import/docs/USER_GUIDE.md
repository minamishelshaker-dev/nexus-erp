## 1. مقدمة عن النظام

### ما هو Nexus ERP؟

نظام **Nexus ERP** هو نظام تخطيط موارد المؤسسات المتكامل المصمم خصيصاً للمؤسسات والشركات الصغيرة والمتوسطة. يوفر النظام حلاً شاملاً لإدارة جميع جوانب الأعمال التجارية من محاسبة ومخزون ومبيعات ومشتريات وتصنيع.

### مميزات النظام الرئيسية

| الميزة | الوصف |
|--------|-------|
| **تعدد المستأجرين** | إدارة عدة شركات من خلال نظام واحد مع عزل كامل للبيانات |
| **المحاسبة المتكاملة** | شجرة حسابات، قيود يومية، تقارير مالية |
| **إدارة المخزون** | تتبع الكميات، حركات المخزون، تنبيهات النقص |
| **المبيعات والمشتريات** | عروض أسعار، أوامر، فواتير مع تكامل محاسبي |
| **التصنيع** | قوائم المواد، أوامر الإنتاج، حساب التكاليف |
| **الذكاء الاصطناعي** | التنبؤ بالطلب، قراءة الفواتير، المساعد الذكي |

### لماذا Nexus ERP؟

- ✅ **سهولة الاستخدام**: واجهة عربية بالكامل مع تصميم حديث
- ✅ **تكامل كامل**: جميع الوحدات متصلة تلقائياً
- ✅ **أمان عالي**: تشفير البيانات وصلاحيات متقدمة
- ✅ **سحابي أو محلي**: يعمل على خوادمكم أو على السحابة
- ✅ **تقارير ذكية**: تقارير قابلة للتخصيص مع رسوم بيانية

## 3. خطوات التثبيت

### 3.1 تثبيت Docker

#### على نظام Windows:

1. قم بتحميل **Docker Desktop** من: https://www.docker.com/products/docker-desktop
2. قم بتشغيل ملف التثبيت واتبع التعليمات
3. أعد تشغيل الجهاز عند الانتهاء
4. تأكد من تفعيل **WSL 2** عند الطلب

#### على نظام macOS:

```bash
# تحميل Docker Desktop for Mac
# من: https://www.docker.com/products/docker-desktop

# أو باستخدام Homebrew
brew install --cask docker
```

#### على نظام Linux (Ubuntu):

```bash
# تحديث الحزم
sudo apt-get update

# تثبيت Docker
curl -fsSL https://get.docker.com | sh

# إضافة المستخدم الحالي لمجموعة Docker
sudo usermod -aG docker $USER

# تثبيت Docker Compose
sudo apt-get install docker-compose-plugin

# التحقق من التثبيت
docker --version
docker compose version
```

### 3.2 تحميل حزمة Nexus ERP

```bash
# استخراج ملف الحزمة
unzip nexus-erp-package.zip

# الدخول لمجلد المشروع
cd nexus-erp
```

### 3.3 التثبيت التلقائي

#### على Windows:

```cmd
# تشغيل سكريبت التثبيت
install.bat
```

#### على Linux/macOS:

```bash
# إعطاء صلاحيات التنفيذ
chmod +x install.sh

# تشغيل سكريبت التثبيت
./install.sh
```

### 3.4 التثبيت اليدوي (خيار متقدم)

```bash
# 1. نسخ ملف الإعدادات
cp .env.example .env

# 2. تعديل الإعدادات (مهم!)
nano .env
# قم بتغيير: SECRET_KEY, JWT_SECRET_KEY, POSTGRES_PASSWORD

# 3. بناء وتشغيل الخدمات
docker compose up -d --build

# 4. انتظار بدء الخدمات (حوالي دقيقة)
docker compose logs -f backend

# 5. تشغيل ترحيلات قاعدة البيانات
docker compose exec backend alembic upgrade head

# 6. تحميل البيانات الأولية
docker compose exec -T postgres psql -U nexus_user -d nexus_erp < docker/demo_data.sql

# 7. التحقق من الخدمات
docker compose ps
```

## 4. الوصول للنظام

### 4.1 فتح النظام

بعد اكتمال التثبيت، افتح المتصفح وانتقل إلى:

```
http://localhost
```

أو إذا قمت بتغيير المنفذ:

```
http://localhost:8080
```

### 4.2 بيانات الدخول الافتراضية

| المستخدم | البريد الإلكتروني | كلمة المرور | الصلاحية |
|----------|------------------|-------------|----------|
| **المدير** | admin@nexus.com | Admin123! | كامل |
| **مستخدم تجريبي** | demo@nexus.com | Demo123! | محدودة |
| **محاسب** | accountant@nexus.com | Acc123! | محاسب |

⚠️ **تنبيه أمني**: قم بتغيير كلمات المرور فوراً بعد أول تسجيل دخول!

### 4.3 تغيير كلمة المرور

1. سجل الدخول بحساب المدير
2. انتقل إلى **الإعدادات** ← **المستخدمون**
3. اختر المستخدم المطلوب
4. اضغط على **تغيير كلمة المرور**
5. أدخل كلمة المرور الجديدة واحفظ

## 5. شرح الوحدات الرئيسية

### 5.1 لوحة التحكم (Dashboard)

لوحة التحكم هي الصفحة الرئيسية التي تعرض ملخصاً شاملاً لحالة النظام:

- **إحصائيات المبيعات**: إجمالي المبيعات اليومية والشهرية
- **حالة المخزون**: المنتجات منخفضة المخزون
- **الفواتير المستحقة**: الفواتير غير المدفوعة
- **التنبيهات**: إشعارات هامة عن النظام
- **الرسوم البيانية**: مخططات الأداء الشهري

### 5.2 المحاسبة (Accounting)

#### شجرة الحسابات

تتضمن شجرة الحسابات الافتراضية:

| المجموعة | الأرقام | الحسابات |
|----------|---------|----------|
| **الأصول** | 1xxx | النقدية، البنوك، المخزون، العملاء |
| **الخصوم** | 2xxx | الموردون، الضرائب، القروض |
| **حقوق الملكية** | 3xxx | رأس المال، الأرباح المحتجزة |
| **الإيرادات** | 4xxx | المبيعات، الخصومات |
| **المصروفات** | 5xxx | تكلفة المبيعات، الرواتب، الإيجار |

#### القيود اليومية

لإنشاء قيد يومي:

1. انتقل إلى **المحاسبة** ← **القيود اليومية**
2. اضغط **قيد جديد**
3. أدخل التاريخ والوصف
4. أضف بنود القيد (مدين/دائن)
5. تأكد من توازن القيد
6. احفظ ثم رحّل

#### التقارير المالية

| التقرير | الوصف |
|---------|-------|
| **ميزان المراجعة** | أرصدة جميع الحسابات |
| **قائمة الدخل** | الإيرادات والمصروفات وصافي الربح |
| **الميزانية العمومية** | الأصول والخصوم وحقوق الملكية |
| **كشف الحساب** | حركات حساب معين |

### 5.3 المخزون (Inventory)

#### المنتجات

لإضافة منتج جديد:

1. انتقل إلى **المخزون** ← **المنتجات**
2. اضغط **إضافة منتج**
3. أدخل البيانات المطلوبة:
   - اسم المنتج
   - الرمز (SKU)
   - سعر التكلفة والبيع
   - الفئة
   - الحسابات المحاسبية
4. احفظ المنتج

#### حركات المخزون

أنواع حركات المخزون:

| النوع | الوصف | تأثير المحاسبة |
|-------|-------|----------------|
| **وارد** | استلام بضاعة | مدين: المخزون / دائن: المورد |
| **صادر** | صرف بضاعة | مدين: تكلفة المبيعات / دائن: المخزون |
| **تحويل** | نقل بين المستودعات | بدون قيد |
| **تسوية** | تعديل الكمية | مدين/دائن: المخزون |

### 5.4 المبيعات (Sales)

#### دورة البيع الكاملة

```
عرض سعر → أمر بيع → تسليم → فاتورة → قيد محاسبي
```

#### إنشاء عرض سعر

1. انتقل إلى **المبيعات** ← **عروض الأسعار**
2. اضغط **عرض سعر جديد**
3. اختر العميل
4. أضف المنتجات والكميات
5. احفظ وأرسل للعميل.

#### تحويل لأمر بيع

1. افتح عرض السعر المؤكد
2. اضغط **تحويل لأمر بيع**
3. سيتم إنشاء أمر البيع تلقائياً

#### إنشاء الفاتورة

1. من أمر البيع المؤكد
2. اضغط **إنشاء فاتورة**
3. راجع البيانات
4. رحّل الفاتورة

### 5.5 المشتريات (Purchases)

#### دورة الشراء الكاملة

```
أمر شراء → استلام → فاتورة مورد → قيد محاسبي
```

#### إنشاء أمر شراء

1. انتقل إلى **المشتريات** ← **أوامر الشراء**
2. اضغط **أمر شراء جديد**
3. اختر المورد
4. أضف المنتجات والكميات والأسعار
5. احفظ وأكد الأمر.

#### استلام البضاعة

1. من أمر الشراء المؤكد
2. اضغط **استلام البضاعة**
3. حدد الكميات المستلمة
4. أكد الاستلام

### 5.6 التصنيع (Manufacturing)

#### قوائم المواد (BOM)

لإنشاء قائمة مواد:

1. انتقل إلى **التصنيع** ← **قوائم المواد**
2. اضغط **قائمة جديدة**
3. حدد المنتج النهائي
4. أضف المواد الخام المطلوبة
5. حدد تكلفة العمالة والتشغيل

#### أمر الإنتاج

1. انتقل إلى **التصنيع** ← **أوامر الإنتاج**
2. اضغط **أمر جديد**
3. اختر قائمة المواد والكمية
4. أكد الأمر وابدأ الإنتاج
5. عند الانتهاء، سجّل الإنتاج

### 5.7 الذكاء الاصطناعي (AI)

#### التنبؤ بالطلب

1. انتقل إلى **الذكاء الاصطناعي** ← **التنبؤات**
2. اختر المنتج
3. حدد الفترة (شهرية/أسبوعية)
4. اضغط **إنشاء التنبؤ**

#### قراءة الفواتير (OCR)

1. انتقل إلى **الذكاء الاصطناعي** ← **قراءة الفواتير**
2. ارفع صورة أو ملف PDF للفاتورة
3. انتظر المعالجة
4. راجع البيانات المستخرجة
5. أنشئ الفاتورة من البيانات

#### المساعد الذكي

1. اضغط على أيقونة **المحادثة** في أسفل اليمين
2. اكتب سؤالك بالعربية
3. مثال: "ما هو رصيد الصندوق؟"
4. سيجيب المساعد بالبيانات المطلوبة

## 6. الأسئلة الشائعة

### س1: نسيت كلمة المرور، ماذا أفعل؟

**ج**: قم بتشغيل الأمر التالي لإعادة تعيين كلمة مرور المدير:

```bash
docker compose exec backend python -c "
from app.core.security import get_password_hash
print('New password hash:', get_password_hash('NewPassword123!'))
"
```

ثم قم بتحديث قاعدة البيانات يدوياً أو تواصل مع الدعم الفني.

### س2: كيف أقوم بعمل نسخة احتياطية؟

**ج**: للنسخ الاحتياطي:

```bash
# نسخ احتياطي لقاعدة البيانات
docker compose exec postgres pg_dump -U nexus_user nexus_erp > backup_$(date +%Y%m%d).sql

# نسخ احتياطي للملفات المرفوعة
docker cp nexus-erp-backend:/app/uploads ./uploads_backup
```

### س3: كيف أضيف مستخدمين جدد؟

**ج**: 
1. سجل الدخول كمدير
2. انتقل إلى **الإعدادات** ← **المستخدمون**
3. اضغط **إضافة مستخدم**
4. أدخل البيانات واختر الدور
5. احفظ المستخدم

### س4: النظام بطيء، كيف أحسّن الأداء؟

**ج**: تأكد من:
- تخصيص ذاكرة كافية (8GB+ موصى بها)
- استخدام SSD للقرص
- التحقق من عدم وجود عمليات ثقيلة على الخادم
- مراجعة سجلات النظام: `docker compose logs`

### س5: كيف أحدث النظام لإصدار جديد؟

**ج**:
```bash
# إيقاف النظام
docker compose down

# تحديث الكود
git pull

# إعادة البناء والتشغيل
docker compose up -d --build

# تشغيل الترحيلات الجديدة
docker compose exec backend alembic upgrade head
```

### س6: هل يمكن تخصيص شجرة الحسابات؟

**ج**: نعم، يمكنك:
- إضافة حسابات جديدة
- تعديل أسماء الحسابات
- تغيير هيكل الشجرة

**تنبيه**: لا تحذف الحسابات المرتبطة بحركات سابقة

### س7: كيف أطبع الفواتير؟

**ج**:
1. افتح الفاتورة المطلوبة
2. اضغط على **طباعة** أو **تصدير PDF**
3. اختر تنسيق الطباعة
4. اطبع أو احفظ كملف
